# 单词掌握度与复习调度算法

本文档描述拼写练习的记忆模型、掌握度等级、熟练度分数与复习调度的设计规范。造句练习不写入本文档定义的记忆状态，也不参与等级与调度。

## 设计原则

- **记忆模型驱动**：掌握度来自 DSR 记忆模型（难度 D、稳定度 S、回忆概率 R）；等级、分数与调度共用同一份事实来源。
- **单一范围**：只有拼写练习的复习写入记忆状态；每次复习等于每轮中对一个词的一次评级。
- **跨天证据**：等级由稳定度档位与去重复习日共同决定，连续突击无法跳过跨天门槛。
- **单调可信**：一次答对不会降低分数，只有真实答错才降级；`mastered` 有可检验的含义。
- **可校准**：每次复习记录复习前的预测回忆概率，校准指标可测量、模型权重可替换。
- **确定性**：抽词排序、同步合并与本文算例都可复现。

## 记忆模型

每个单词保存一份 DSR 状态：

- **难度 D**：1–10。难词稳定度增长更慢、答错时下降更多。
- **稳定度 S（天）**：回忆概率从 100% 降到 90% 所需时间。期望保留率 90% 时，下次复习间隔 = `round(S)` 天。
- **回忆概率 R**：距上次复习 t 天时的预测回忆概率。

遗忘曲线：

```
decay = −w20 = −0.1542
factor = 0.9^(1 / decay) − 1 = 0.980346
R(t, S) = (1 + factor × t / S)^decay
```

`t` = 距上次复习的毫秒差整除 24 小时：不足 1 天记为 0，走同日更新；首次复习没有 R。

**初始值**（首次复习按评级写入）：

```
S₀(G) = max(w[G − 1], 0.1)
D₀(G) = clamp(w4 − e^((G − 1) × w5) + 1, 1, 10)
```

默认值：S₀（Again / Hard / Good）= 0.212 / 1.2931 / 2.3065；D₀（Again / Hard / Good）= 6.4133 / 5.1122 / 2.1181。Easy 评级当前不产生，参数保留默认值。

**评级更新**：

- 答对（Good）：`S′ = S × (1 + e^w8 × (11 − D) × S^(−w9) × (e^(w10 × (1 − R)) − 1))`
- 答对但用过提示（Hard）：在 Good 公式上再乘 `w15`。
- 答错（Again）：`S′ = min(w11 × D^(−w12) × ((S + 1)^w13 − 1) × e^(w14 × (1 − R)), S ÷ e^(w17 × w18))`，下限 0.001。
- 同日复习（t = 0）：`S′ = S × S^(−w19) × e^(w17 × (G − 3 + w18))`；Hard/Good 再取 `max(S′, S)`，保证不下降。

**难度更新**：

```
ΔD = −w6 × (G − 3)
D′ = clamp(w7 × D0(Easy) + (1 − w7) × (D + ΔD × (10 − D) / 9), 1, 10)
```

`D0(Easy)` 按初始难度公式代入 Easy 的原值；Good 不改变难度方向，Hard / Again 提高难度。

**状态机**：

| 状态 | 含义与去向 |
| --- | --- |
| new | 从未复习；首次复习后进入 learning |
| learning | 学习步（1 分钟、10 分钟）；Good 前进、走完进入 review；Again 回到第一步；Hard 停留当前步（约 6 分钟） |
| review | 常规复习；答错进入 relearning，否则按新 S 计算间隔 |
| relearning | 再学习步（10 分钟）；Good 回到 review；Again 留在再学习步；Hard 停留（约 15 分钟） |

**复习间隔**：`interval = clamp(round(S × (期望保留率^(1 / decay) − 1) / factor), 1, 36500)`。期望保留率 90% 时乘数为 1，即 `interval = round(S)` 天。

## 复习与评级

- **一次复习**：每轮中该词第一次完成的输入决定评级并写入记忆状态；同一轮内之后清空重打不改变评级，也不产生新复习。
- **评级映射**：

| 一轮中的表现 | 评级 |
| --- | --- |
| 首次完成的输入错误 | Again |
| 首次完成正确、用过提示 | Hard |
| 首次完成正确、未用提示 | Good |

- 提示每轮最多计一次；未完成的输入（中途离开、未输到词长）不产生复习。
- **每日上限**：每个词每天最多 3 次复习（含学习步与再学习步）；达到上限后当天不再抽到。
- 常规 `review` 状态的词每天只产生一次复习；同日再次出现只发生在学习 / 再学习步内。

## 掌握等级与熟练度分数

**稳定度档位**：

| 等级 | 条件 |
| --- | --- |
| new | 无复习记录 |
| learning | S < 1 天 |
| familiar | 1 ≤ S < 7 天 |
| proficient | 7 ≤ S < 30 天 |
| mastered | S ≥ 30 天 |

**复习日解锁**（复习日 = 发生过复习的本地日期，去重；跨设备同日只计一次）：

| 复习日数 | 最高等级 |
| --- | --- |
| 1 | learning |
| 2 | familiar |
| 3 | proficient |
| ≥4 | mastered |

有效等级 = min(稳定度档位, 复习日解锁档位)。

**熟练度分数**（0–100，仅展示）：按有效等级落区间，区间内按 S 单调推进。

| 有效等级 | 区间 | 公式 |
| --- | --- | --- |
| learning | 20–39 | `20 + 19 × min(S, 1)` |
| familiar | 40–59 | `40 + 19 × min((S − 1) / 6, 1)` |
| proficient | 60–79 | `60 + 19 × min((S − 7) / 23, 1)` |
| mastered | 80–100 | `80 + 20 × min((S − 30) / 335, 1)` |

new 显示为未练习、不计分。分数只用于展示；调度只由 S、R 与到期日决定。

**语义**：`mastered` 表示模型估计 30 天后仍有 90% 把握回忆；`S = 365` 对应 100 分。答错会降低 S、可能降级；复习日数只增不减。

## 复习调度与轮次抽词

- **期望保留率**：0.9；到期复习按预测 R 从低到高优先。
- **每轮词数 N**：默认 5。
- **轮次构建顺序**：
  1. 学习 / 再学习步到期（state 为 learning / relearning 且 `due ≤ 现在`）：按 `due` 升序。
  2. 到期复习（state 为 review 且 `due ≤ 现在`）：按 R 升序。
  3. 新词（state 为 new）：配额 `min(2, floor(N / 2))` 个，按 `createdAt` 升序。
  4. 补位：以上不足时，先补已练过的词（按 R 升序）；仍不足时用其余新词按 `createdAt` 升序填满轮次——已练词充足时新词不超过配额，不足时允许填满。
- **排除规则**：同一轮不重复；当天复习次数已达 3 的词跳过；补位不选当天已复习过的词。
- **并列排序**：R 与 `due` 相同时按 `hash(词 id + 本地日期)` 排序，同一天内结果稳定、跨天自动轮换。
- 造句练习从词库中均匀随机选词，不读写本章的记忆状态与复习日志（规则见 `docs/architecture/sentence-deepseek.md`）。

## 拼写流畅度（展示项）

流畅度只回答「这个词比平时打得顺不顺」，不参与记忆状态、等级、分数与调度。

- **数据**：最近 20 次拼写正确输入耗时（秒）。
- **个人基线**：按词长分档（≤5 / 6–10 / ≥11），取同档**其他词**耗时的中位数；样本 ≥5 时生效，否则回退 `0.4 × 词长 + 0.5` 秒。
- **计算**：取该词最近 5 条耗时，剔除 `> 5 × 基线` 的异常样本；清洗后不足 3 条不展示，否则 `流畅度 = clamp(round(80 × 基线 ÷ 中位数(清洗后样本)), 0, 100)`。
- 80 分表示与平时同档同速；造句不产生计时。

## 数据模型

`users/{uid}/words/{docId}` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| word / translation / createdAt | — | 词条自身信息 |
| memory.stability | number | 稳定度 S（天） |
| memory.difficulty | number | 难度 D（1–10） |
| memory.state | string | new / learning / review / relearning |
| memory.learningSteps | number | 当前学习步下标 |
| memory.due | number | 下次可复习时间（epoch ms） |
| memory.lastReviewAt | number \| null | 最近复习时间 |
| memory.lastGrade | number \| null | 最近评级（1 答错、2 Hard、3 Good） |
| memory.reps / memory.lapses | number | 累计复习次数 / 答错次数 |
| memory.modelVersion | string | 生效模型版本，当前 `fsrs-6` |
| stats.reviewDays | number | 去重复习日总数 |
| stats.lastReviewDay | string \| null | 最近复习的本地日期 `YYYY-MM-DD` |
| stats.dailyReviews | number | `lastReviewDay` 当天的复习次数 |
| stats.hints | number | 用过提示的复习次数（累计复习次数见 memory.reps） |
| inputTimes | number[] | 最近 20 次拼写正确耗时（秒） |
| reviews | array | 复习日志，上限 200 条 |

复习日志条目：`{ id, at, g, h, r, s, d }`：全局唯一 id、epoch ms、评级（1 / 2 / 3）、是否用过提示、复习前预测 R（首次复习无预测值，记 null）、复习后 S、复习后 D。

- 未复习的新词：`memory.state = new`、`stability = 0`、`difficulty = 0`、`due = createdAt`、`lastReviewAt = null`、`reps = lapses = 0`；`stats` 全为 0 / null。
- 每次复习维护复习日：本地日期与 `lastReviewDay` 不同时，`reviewDays` 加 1、`lastReviewDay` 更新为今天、`dailyReviews` 置 1；相同时只 `dailyReviews` 加 1。
- 时间统一存 epoch 毫秒；统计用的「本地日期」按客户端时区生成。
- 重置练习数据 = 清空 memory、stats、inputTimes、reviews，回到 new。

## 同步与合并

- `memory`：取 `lastReviewAt` 更晚的一侧；相同取 `stability` 更低的一侧。记忆状态包含全部历史信息，按状态整体合并即可。
- `reviews`：按 `id` 并集去重，按 `at` 升序，保留最近 200 条。
- `stats`：`reviewDays`、`hints` 取较大值；`lastReviewDay` 取较晚日期；`dailyReviews` 同日取较大值，异日跟随较晚的日期。
- `inputTimes`：合并后保留最近 20 条。
- 单词归一化导致两个文档合并时使用同一组规则：`memory` 按 `lastReviewAt`、`reviews` 并集、`stats` 取大、`inputTimes` 取最近 20 条。
- 写入以单词文档为单位，沿用词库同步的队列、分片与失败提示机制。

| 参数 | 默认值 |
| --- | --- |
| 期望保留率 | 0.9 |
| 每轮词数 N | 5 |

| 等级稳定度阈值 | 1 / 7 / 30 天 |

**调参入口**：复习太频繁 → 降低期望保留率（扩大间隔）；想更快引入新词 → 提高每轮新词配额；升级太难或太易 → 调整等级稳定度阈值；单日复习过于密集 → 降低每词每日上限。

**评级映射**：首次输入错误 → Again；用过提示 → Hard；独立答对 → Good。

## 校准与监控

- 每次复习把复习前预测的 R 写入 `reviews[].r`；首次复习（`r = null`）与相邻复习间隔不足 1 天的样本不参与校准（学习步不是延迟回忆测试）。
- **校准指标**：
  - 可靠性：按预测 R 分区间，比较每区预测均值与实际回忆率（评级 Hard / Good 视为回忆成功，Again 为失败）。
  - 预测误差：Brier 分数与 AUC。
  - 调度：到期词当天出现的比例、间隔随 S 的增长、达到各等级所需的复习次数与天数。
- **权重更新**：当前保留的复习日志中累计 ≥500 条可校准样本后，用官方 `fsrs-optimizer` 离线拟合该用户权重，发布新的 `modelVersion`；既有 S / D 保留，之后的更新与间隔按新权重计算。`export-review-logs` 工作流每周自动检查并在达标时创建 Issue 提醒；导出、拟合与发布流程见 `docs/DEPLOYMENT.md`「熟练度校准」。
- 校准结果同时用于检验评级映射：若用过提示的复习与独立答对的后续回忆率无差异，应把提示调整为更低评级或单独统计。

## 存量数据迁移

存量单词文档由 `scripts/migrate-words-v2.mjs` 一次性批处理迁移到本文档的字段结构：

- 删除 `correctCount`、`totalAttempts`、`lastPracticedAt`、`correctPracticeDates`、`attemptHistory`，已有的熟练度、练习次数与计时样本全部清除。
- `memory` 重置为 new、`stats` 置零、`inputTimes` 与 `reviews` 置空；保留 `word`、`translation`、`createdAt`。
- 迁移幂等：已有 `memory` 的文档只清理旧字段，不覆盖迁移上线后产生的练习数据。

脚本默认 dry-run，`--apply` 才写入；运行方式与顺序见 `docs/DEPLOYMENT.md`。

## 附录：算例

**新词成长（连续独立答对）**

| 复习 | 间隔 | R | 更新后 S | 更新后 D | 下次间隔 |
| --- | --- | --- | --- | --- | --- |
| 第 1 次 | — | — | 2.3065 | 2.1181 | 学习步 10 分钟 |
| 同日第 2 次 | 0 天 | 1.000 | 2.3065 | 2.1112 | 2 天（毕业） |
| 第 3 次 | 2 天 | 0.909 | 10.971 | 2.1043 | 11 天 |
| 第 4 次 | 11 天 | 0.900 | 46.317 | 2.0975 | 46 天 |

第 4 次之后复习日为 3 天：S 已到 mastered 档（≥30 天），复习日只解锁到 proficient，有效等级为 proficient，分数 = 79；第 4 个复习日即解锁 mastered。

**逾期答错（沿用上表 S = 10.971、D = 2.1043）**

30 天后复习且答错：R = 0.818；答错公式给出 S_f = 1.761，低于上限 `S ÷ e^(w17 × w18) = 10.44`，因此 S′ = 1.761；进入再学习步（10 分钟）。等级回到 familiar（复习日仍是 3 天，但 S < 7），分数 = 42。

**等级与分数示例**

| S（天） | 复习日 | 有效等级 | 分数 |
| --- | --- | --- | --- |
| 0.5 | 1 | learning | 30 |
| 2.3065 | 1 | learning | 39 |
| 2.3065 | 2 | familiar | 44 |
| 10.971 | 2 | familiar | 59 |
| 10.971 | 3 | proficient | 63 |
| 30 | 4 | mastered | 80 |
| 365 | ≥4 | mastered | 100 |

**术语**

- **DSR**：难度（Difficulty）、稳定度（Stability）、回忆概率（Retrievability）。
- **评级**：Again / Hard / Good，对应答错 / 用过提示 / 独立答对。
- **学习步 / 再学习步**：新词与答错词在短时间内再次出现的步骤。
- **复习日**：发生过复习的本地日期，去重计数。
- **期望保留率**：调度试图维持的到期回忆概率。
